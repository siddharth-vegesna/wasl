PitchSimulationKitLive demo
The live demo is three machines.

Wasl is a camp phone, a small computer in a water truck, and a clinic laptop exchanging messages with no internet between them. That cannot run on a static web page, so run it yourself below. The truck node is designed for a Raspberry Pi; so far it has run on a laptop, with radio range emulated.

Code on GitHubNetwork simulation
Run all three on your laptop

Python 3 only. No installs, nothing fetched from the internet.

git clone https://github.com/siddharth-vegesna/wasl.git
cd wasl
./scripts/run-local.sh

Then open http://localhost:8081/stage: the phone, the truck and the clinic side by side, with buttons that move the truck in and out of range.
